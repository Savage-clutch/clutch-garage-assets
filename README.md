# Clutch Garage assets

A read-only mirror of the brand files on [the Garage](https://garage.clutch.ca), Clutch's brand guidelines, so AI
agents and code sandboxes that can reach GitHub but not garage.clutch.ca can still use real Clutch assets.

**Don't edit anything here.** The Garage is the source of truth. A GitHub Action checks it every hour, adds new and
changed files, and deletes anything that was removed or hidden on the Garage. Manual changes get overwritten.

## What's here

| Folder | Contents |
|---|---|
| `logos/` | Hero, CTA and Emblem logos in red, white and plum (SVG, PNG, AI, EPS), co-brand lockups |
| `icons/` | The 2D icon set (SVG), for product UI only |
| `clutch-moments/` | Clutch Moments (3D icons) |
| `colours/` | Colour files |
| `fonts/` | Poppins, the fallback typeface. Circular is a licensed font and is never mirrored. |
| `media-kit/` | Clutch Media Kit photos (`<asset number>-<title>.<ext>`). Videos over 95 MB stay on the Garage only. |

[INDEX.md](INDEX.md) lists every file with its download link. Raw link pattern:
`https://raw.githubusercontent.com/Savage-clutch/clutch-garage-assets/main/<path>`

## For AI agents

Read the rules before using anything: https://garage-external.vercel.app/brand.md (live from the Garage). Use the
logo colour that matches the background, never recolour or redraw assets, and never invent new ones.

## Usage

These files are Clutch brand assets, provided for work on Clutch's behalf. Media Kit photography is © its
photographers. Follow the Garage guidelines for every use.
